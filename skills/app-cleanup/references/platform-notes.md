# 平台与应用边界

只在相应分支实际涉及时使用；这里的操作要在读取范围或类别授权后执行。

## 原生操作与平台差异

- macOS：应用包、CLI、用户 Library 数据、Finder workflow 和钥匙串分属不同对象。用系统 Trash API 获得实际落点并验证，不手工猜重名规则。`security find-generic-password` 不加显示密码选项，仅查询精确服务/账号；密码库锁定时由用户自行解锁，删除凭据不是文件移入废纸篓。
- Windows：安装记录、实际安装位置、用户/系统 AppData、快捷方式、计划任务和凭据分开核对。原生卸载与回收站能力取决于安装方式；不要手删共享依赖、注册表大分支或将所有文件都承诺可从回收站恢复。
- Linux：先区分系统包、用户包、容器、AppImage、Flatpak/Snap 和手工 CLI；保持包管理器一致性。遵守 XDG 路径与真实安装方式，不把整个 `~/.config` 或共享依赖目录当专属残留。终端 `rm` 不是可恢复废纸篓。

跨平台脚本只验证观测得到的对象；原生废纸篓可恢复性、卸载注册、凭据存在性、服务运行状态由平台检查器另证。没有能力时标明具体受阻项，不尝试权限绕过。

## 浏览器

- 先确定浏览器和配置文件，分别保护书签及其备份、保存标签组/条目和会话恢复状态。站点数据不是书签；保留记录中的关键词是有意保留，不是失败。
- 优先原生 UI 的站点删除和按关键词筛选后的历史删除，检查选择是否只限当前筛选结果。不能用清空全部历史、全部 Cookie 或整个 profile 替代定向清理。
- 记录查询范围及条件；UI 无结果只证明该入口的结果。必须验证底层本地记录时，读取实际数据库/原生接口补核，不能把截断列表当全覆盖。
- 只读 SQLite 连接不等于文件级原子快照；普通复制活动数据库也不是快照。只有确认关闭/停写或采用有效一致性机制后才能做离线写入。若不能正常退出，不强杀用户进程。
- 离线写入之前读取本版本真实表结构和关系、明确同步影响；不能把历史访问关联、Cookie、IndexedDB、权限、OAuth 来源和保存标签组混成一个对象。不复制本次会话里的固定 SQL 成为跨版本卸载工具。
- 原生权限重置可能生成新的站点元数据；“重置成功”不保证关键词文件项消失。按用户已确认的结果语义判定，不反复重置或扩大范围追求字面无命中。
- 保留云端同步状态和会话恢复文件时，后续可能重现历史；说明时点和边界，不擅自删除云账号、邮件、聊天或关闭同步。

## 共享工具、会话与项目

- 模型配置、渠道/凭据、请求统计、技能启用关联和会话内容分开分类；共享技能/MCP 定义不能因为一个应用关联而整项删除。
- 会话分类使用 session 当前模型和所有 user/assistant 消息模型元数据；只看 session 模型名不能证明专属。缺失、未知模型或关联不明的会话先保留并报告，不强行归类。
- 核查父子会话、结构化交叉引用、共享快照及外部文件。父子或引用组内有其他模型会话时整体保留，除非用户另行确认安全拆分。不能只删父节点留下不可用的其他模型子会话。
- 数据库删除用本版本外键/关系及事务，不清空整个混合库。保留行内容比较与完整性检查是不同断言，都应按影响覆盖。会话专属外部缓存须按实际 session id 映射；共享快照/日志无法可靠拆分时不猜删。
- `CLAUDE.md`、`.claude/worktrees`、教程、图片、团队规则等是工作资料，不自动视为卸载残留；清理需另获确认，核对 Git 状态、真实内容和引用，保护未提交工作。
- 活动终端可能把内存历史重新写回文件；不要因用户确认删磁盘历史就自动关闭终端或删除全部历史。按可操作范围验证，指出再生条件。
